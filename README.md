# I use arch btw

A tiny programming language. Run with `python3 iuab.py examples/hello.arch`.

Every program must start with `I use arch btw`, or it refuses to run.

| Statement | Meaning |
|---|---|
| `pacman -S x <expr>` | install (set) a variable |
| `echo <expr>` | print |
| `if <expr>` / `else` / `fi` | conditional |
| `while <expr>` / `done` | loop |
| `# ...` | comment |

Expressions support numbers, strings, `+ - * / // % **`, comparisons, `and`/`or`/`not`.
